MEASURE, THEN COMPARE

Three paths. The same target model.

Compare uncached generation, explicit KV cache reuse, and greedy speculative decoding on the current record and first criterion. Each path gets one warmup and two timed runs generating 16 raw tokens. CPU execution can take a few minutes.

KV cache

Reuse past attention keys and values while advancing absolute token positions. The reference recomputes the complete prefix.

Speculative decoding

A six-layer pruned draft proposes tokens. The target verifies a block, accepts its matching prefix, corrects a rejection, and crops both caches.

Tiled online-softmax attention

The educational implementation maintains running row maxima, normalization sums and weighted values across tiles. Numerical errors, timings and process memory are available in Study results. It is tested separately and does not replace the model’s attention backend.
